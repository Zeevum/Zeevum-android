# Zeevum-android
Клиент мессенджера Zeevum: Rust + Slint. Windows-сборка доступна в релизах

Android — целевая платформа, в разработке

## Экосистема
- [Zeevum-server](https://github.com/Zeevum/Zeevum-server) — сервер
- Zeevum-android — этот репозиторий
- [Zeevum-protocol](https://github.com/Zeevum/Zeevum-protocol) — общий крейт протокола

## Возможности
1. Регистрация и вход: по логину и паролю, автологин по токену сессии
2. Локальный индикатор стойкости пароля при регистрации (при помощи zxcvbn)
3. Приватные чаты пользователь-пользователь: история сообщений, статусы (Отправляется | Доставлено | Прочитано)
4. Друзья: поиск по логину, отправка и принятие заявок
5. Оффлайн действия: сообщения и события, отправленные оффлайн пользователю, он увидит после подключения (открыв чат)
6. Автологин: адрес сервера и сессия сохраняются локально

## Ограничения
- Android-сборка и хранение настроек по правилам Android ещё не реализованы (файл настроек сейчас рассчитан на ПК платформы)
- При отключении от сервера кэш переписки сбрасывается (история догружается с сервера при открытии чата)
- Несколько устройств одного пользователя одновременно не поддерживаются

## Требования
- Rust 1.85+
- Cargo
- Работающий [Zeevum-server](https://github.com/Zeevum/Zeevum-server)
- Доверенный TLS-сертификат сервера (Let's Encrypt или mkcert)

## Сборка и запуск
```bash
git clone https://github.com/Zeevum/Zeevum-android.git
cd Zeevum-android
cargo run
```
UI описан в `ui/app.slint`, логика — в `src/`:
1. network.rs — соединение, TLS, рукопожатие, разбор протокола
2. controller.rs — состояние приложения и связка сеть с UI
3. settings.rs — локальное хранение сессии (zeevum_client_settings.json в каталоге конфигурации)

### Несколько экземпляров на одной машине (разные аккаунты):
Терминал 1:
`$env:MUC_PROFILE="a"; cargo run`
Терминал 2:
`$env:MUC_PROFILE="b"; cargo run`
Каждый профиль хранит свой файл настроек.
> Количество профилей можно запускать множество. Кроме профилей `a`, `b` подойдут такие как `c`, `d` и т.д.

## Первые шаги
1. Подключение к серверу. На экране настроек нужно указать адрес сервера к которому нужно подключиться (host:port), например: `127.0.0.1:1990` или `my.host.com:1990` 
2. Регистрация. После успешной регистрации клиент автоматически войдёт в профиль. После этого можно будет выходить из аккаунта и логиниться по логину и паролю
3. Поиск пользователя. Пользователя нужно найти по логину, при нажатии на поиск, если такой пользователь будет найден в системе, ему отправится заявка в друзья. После принятия собеседник появится в списке чатов
